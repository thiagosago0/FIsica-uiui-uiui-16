# Física do Zero

Uma página interativa para revisar conteúdos de Física do ensino médio. Inclui:

- teoria organizada por assunto, com resumos de fórmulas;
- simulado com questões de múltipla escolha e explicações;
- flashcards para revisar conceitos.

## Publicar no GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.

Após a publicação, o GitHub Pages exibirá o endereço do site na mesma tela. A página inicial é o arquivo `index.html`.

## Visualizar localmente

Abra `index.html` em um navegador. Não é necessário instalar dependências nem executar um processo de build.
